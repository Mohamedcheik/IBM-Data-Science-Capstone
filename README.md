# IBM Data Science Capstone – SpaceX

## Project Overview

This repository contains my work for the IBM Data Science Professional Certificate Capstone Project.

The objective of this project is to analyze SpaceX Falcon 9 launch data and develop machine learning models to predict the success of the first-stage rocket landing.

The project covers the complete data science workflow, from data collection and preparation to exploratory data analysis, interactive visualization, and predictive modeling.

## Project Structure

| Folder | Description |
|---|---|
| `01_Data_Collection` | SpaceX API data collection |
| `02_Web_Scraping` | Collecting launch data through web scraping |
| `03_Data_Wrangling` | Data cleaning and preparation |
| `04_EDA_Visualization` | Exploratory data analysis and visualizations |
| `05_EDA_SQL` | Exploratory analysis using SQL |
| `06_Folium_Maps` | Interactive geographical analysis using Folium |
| `07_Plotly_Dash` | Interactive SpaceX launch dashboard |
| `08_Machine_Learning` | Predictive analysis and classification models |

## Project Objectives

- Collect SpaceX launch data using APIs and web scraping.
- Clean, transform, and prepare the collected datasets.
- Explore launch data using Python and SQL.
- Identify patterns and relationships affecting landing success.
- Visualize launch sites and geographical relationships.
- Develop an interactive dashboard using Plotly Dash.
- Build and evaluate machine learning classification models.
